Bug_Track — event detection for field-biology videos

A video-analysis tool built for a biology field experiment: it finds the timestamps of predation events automatically.

GITHUB ↗

Motivation

In my second year of high school, a friend in the biology program was running a field experiment: whether spider webs of different shapes differ in predation efficiency. The method was to record webs with field cameras over long periods, then log every predation event and its timestamp by hand.

That workflow had three problems. Outdoor lighting shifts hard and the background is noisy, so image quality is unstable. Labeled insect samples were too few to build a supervised dataset, which ruled out trainable detectors like YOLO. And manual annotation is slow; with observer fatigue and subjective judgment differing between members, the logged results were often inconsistent, which weakened the data.

Requirements first

Before writing any code I sat down with him and fixed the requirements: how precise the marks needed to be, how small the detected objects were, how much test data there was, and what computational budget the tool had. Settling the spec first kept the design aligned with the experiment.

System design

The tool is an event-filtering pipeline built on computer vision. Videos are first split along the time axis into segments, which bounds memory use and keeps processing stable. Each segment goes through image processing to suppress lighting variation, then inter-frame differencing to detect motion. Consecutive frames above the threshold are merged into one event span, so a single catch is not logged as several separate hits.

The interface is a GUI: pick the video, set the parameters, run the analysis, inspect the results. Researchers without a CS background operate the whole flow themselves.

Outcome

Manual annotation time dropped sharply, results no longer varied by observer, and the data became more reliable. The code is public on GitHub.
