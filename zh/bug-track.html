Bug_Track——野外生態影片事件偵測工具

為生物組的野外實驗寫的影片分析工具，自動找出捕食事件的時間點。

GITHUB ↗

設計動機

高二時，生物組的朋友在做野外觀察實驗：研究不同形狀的蜘蛛網在捕食效率上是否有差異。實驗方法是長時間錄製野外蜘蛛網的監控影片，再人工記錄每次捕食的發生與時間點。

這個流程有三個問題。野外光照變化劇烈、背景干擾多，影像品質不穩定。能標註的昆蟲樣本太少，建不出監督式資料集，YOLO 這類需要訓練的偵測模型用不了。人工標註本身耗時，加上觀察疲勞和組員間的主觀判斷差異，標註結果常常不一致，數據可靠性因此打折。

系統設計

長影片先用 FFmpeg 沿時間軸切成固定長度的分段，逐段解碼分析，記憶體用量不隨影片長度成長。每段逐幀計算變化分數；偵測器做成可抽換的模組，共實作十種方法：稠密光流、稀疏光流、ORB 特徵匹配、幀間差異、直方圖差異、運動輪廓、區塊化局部差異、邊緣變化偵測、小物體光流變體，以及基於幀緩衝的時間差分。光照漂移、目標大小、移動速度等拍攝條件不同時，換方法只是改一個執行參數，不用改程式。

輸出是變化分數的時間序列：超過偵測閾值的區段標記為候選事件，連續超標的影格合併成單一事件區段，結果繪成圖表並可輸出 JSON 供後續統計。

PyQt5 介面把管線參數——影片與輸出路徑、分段長度、偵測閾值、分析方法——直接開放在視窗上，並顯示切片與圖表產生進度。非資訊背景的研究人員可以自己跑完整個分析。

成果

人工標註時間大幅縮短，標註結果不再因觀察者而異，數據可靠性提高。程式碼公開在 GitHub。
