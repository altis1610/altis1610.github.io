ebook2pdf — online ebook readers to clean PDFs

A batch pipeline: automatic page turning, capture, cropping, and merging.

GITHUB ↗

Motivation

Some reference material I had legitimate access to is only served through page-by-page online readers: no download, no annotation, no offline access. For personal offline reading and note-taking, it first has to become a PDF.

System design

The tool drives Chrome through Selenium (ChromeDriver is fetched automatically). The user logs in and opens the first page; from there the script takes over — it simulates page turns, captures a screenshot per page, crops the reader chrome and margins from each image, and compiles the batch into a single PDF. Project name and page count are parameters, so one run handles an entire book without further input.
